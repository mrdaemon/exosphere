# 3.0.3 - Optional Bugfix Release

*WIP - Development Build - Notes not Final*

Contains minor, optional changes surrounding dependencies compatibility, and
an edge case fix for the `--version` flags from the CLI.

## Bug Fixes

- Ensure Compatibility with Cyclopts >=4.16.1<6.0.0
- `--version/-V` now only skips initialization when used as a root argument.
  Using it after a subcommand will now correctly gets a standard error and help
  output.
