# 3.0.3 - Optional Bugfix Release

Contains minor, optional changes surrounding dependencies compatibility, support
for Python 3.15 and an edge case fix for the `--version` flags from the CLI.

## Features

- Python 3.15 support

## Bug Fixes

- Explicitly handle CLI exit codes to prevent future breakage due to library changes
- `--version/-V` now only skips initialization when used as a root argument.
  Using it after a subcommand now correctly gets a standard error and help output.

## Dependency Changes

- Floor raised for Pydantic on Python 3.15 (pydantic 0.14, pydantic-core 0.50).
  Unchanged on 3.13 and 3.14.
- Cyclopts ceiling set to < 6.0.0
