# 3.0.2 - Bugfix Release

A minor change in dependencies to prevent an incompatible version of a library from
being used, as well as URL changes for docs and home page.

## New website

Exosphere now has a mini-site at [exosphere.tools](https://exosphere.tools).
The documentation has been re-homed under [docs.exosphere.tools](https://docs.exosphere.tools)
for consistency, although previous readthedocs links should still continue to function.

A few internal changes also improve how this information is shared between
the components that make use of it, to ease any further change of that kind.

## Bug Fixes

- Fixed an issue where Exosphere would pull an incompatible version of a dependency
  on install through pipx or uv tools, resulting in exit code changes.

## What's Changed

- Project: Change homepage and docs urls
- Update documentation URLs
- Docs: Update spellcheck words list
- Update lockfile dependencies
- Deps: restrict cyclopts to <5.0.0
